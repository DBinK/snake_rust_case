# 01 需求

## 做什么

一个终端贪吃蛇：`O` 是蛇、`*` 是食物、`.` 是空地。方向键或 h/j/k/l 转向，
吃到食物变长加分，撞墙或咬到自己游戏结束，q / Esc 退出。

```
  Score: 3   (h/j/k/l or arrows, q to quit)
  ....................
  ....................
  ..........*.........
  ....................
  ........OOOO........
  ...........O........
  ....................
  ....................
```

## 功能清单

1. 20×12 棋盘，蛇初始 1 节，位于中央，向右移动。
2. 起步节拍 200ms，每吃一块食物 -10ms，下限 60ms；输入只在步进间隙生效，快速连按不丢。
3. 禁止 180° 反向（直接撞死自己太蠢）。
4. 食物随机落在空格；吃食 +1 分并立刻刷新下一块。
5. 撞墙、咬到自己 → Game Over 画面，按 q 退出。
6. 退出后终端恢复原状（raw mode / alternate screen 必须归还）。

## 非目标

无分数持久化、无加速机制、无彩色渲染 —— 刻意砍掉的，
每条都在真实项目里值得做，但每一条都会稀释语言教学密度。

## 对照 C / Python 读者

这个项目只有一个难点：**终端交互**。raw mode、键盘事件、
按帧重绘 —— 你在 C 里要手写 termios，Python 里交给 curses，
Rust 里用 crossterm。游戏逻辑本身你十分钟就能写完，
所以每行代码省下来的认知预算，全部花在 Rust 特有的地方：
所有权、enum、Result、借用检查、RAII。
